# EA1: Manipulación de Vectores en Java
**Estudiante:** Miguel Adolfo Arango Monsalve  
**Programa:** Ingeniería de Software y Datos (IU Digital)  

### Descripción de la Actividad
Programa en Java desarrollado en VS Code con JDK Eclipse Temurin que realiza operaciones sobre un vector de 15 números enteros (validación de rangos entre 10 y 100, búsqueda de valores, determinación del número mayor y menor, identificación de múltiplos de X, cálculo de la suma total y creación de un nuevo vector con los números que están por encima del promedio).
